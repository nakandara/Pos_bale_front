🦀 Tauri කියන්නේ මොකක්ද?
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Desktop apps හදන්න පුළුවන් modern framework එකක්.

✅ Electron වලට වඩා:
   • 15x smaller (5 MB vs 80 MB)
   • 4x less memory
   • Faster startup
   • Better security (Rust)


📋 STEP 1: Rust Install කරන්න (වැදගත්!)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

Option 1 (default) select කරන්න, පසුව:

source $HOME/.cargo/env

Verify:
rustc --version
cargo --version


📦 STEP 2: System Dependencies
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

sudo apt update
sudo apt install -y libwebkit2gtk-4.1-dev build-essential \
    curl wget file libssl-dev librsvg2-dev libayatana-appindicator3-dev

(මිනිත්තු 2-3ක් විතර)


🚀 STEP 3: Tauri Initialize කරන්න
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

cd /home/pramod/POS/react-ts-app
npx tauri init

Prompts (සියල්ලටම Enter press කරන්න defaults සඳහා):

  App name: myapp-dashboard ⏎
  Window title: MyApp Dashboard ⏎
  Web assets: ../dist ⏎
  Dev server URL: http://localhost:5173 ⏎
  Frontend dev: npm run dev ⏎
  Frontend build: npm run build ⏎


⚡ STEP 4: Development Run කරන්න
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

npm run tauri:dev

⏳ පළමු run එක slow වෙනවා (Rust compile - මිනිත්තු 2-3)
⚡ ඊළඟ runs fast වෙයි!


📦 STEP 5: Production Build කරන්න
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

npm run tauri:build

Output: src-tauri/target/release/bundle/
  ├── appimage/*.AppImage  (click කරලා run)
  └── deb/*.deb           (install කරන්න)

⚠️ Common Issues
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. "rustc not found"
   → Rust install කරන්න (Step 1)

2. "webkit2gtk not found"
   → System deps install කරන්න (Step 2)

3. "Port 5173 already in use"
   → lsof -ti:5173 | xargs kill -9

4. Build slow
   → පළමු build එක slow - ඊළඟ builds fast

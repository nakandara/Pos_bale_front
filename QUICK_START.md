# 🚀 Quick Start - PWA with Notification Badges

## Step 1: Generate Icons (2 minutes)

1. Open `generate-icons.html` in your browser
2. Click "Generate All Icons"
3. Move downloaded icons to `/public` folder

## Step 2: Run Your App

```bash
npm run dev
```

## Step 3: Test Locally

Open http://localhost:5173 in your browser

## Step 4: Deploy to HTTPS

Deploy to Vercel, Netlify, or any HTTPS hosting:

```bash
npm run build
# Upload 'dist' folder to your hosting
```

## Step 5: Install on Mobile

### Android:
1. Open your website
2. Tap menu (⋮) → "Add to Home screen"

### iOS:
1. Open in Safari
2. Tap Share → "Add to Home Screen"

## Step 6: Test Notification Badge

1. Open installed app
2. See notifications (currently showing 2 unread)
3. Close app completely
4. Check home screen - badge shows "2"
5. Open app, mark as read
6. Close app - badge updates!
